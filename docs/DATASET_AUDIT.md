# Location catalog audit

Generated by `npm run audit:dataset`. Do not edit by hand — regenerate it.

A **canonical group** is one distinct *place*. Several catalog rows collapse into one group when they share an explicit group id, resolve to the same panorama, or sit within 1 km of each other. Perceived variety is governed by group count, never by row count.
